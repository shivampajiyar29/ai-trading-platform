# AI Trading Platform

A modular, AI-powered global trading platform designed for market intelligence, strategy development, backtesting, paper trading, broker connectivity, user model training, and controlled automated trading.

## Important

This repository is being built incrementally by multiple AI engineering agents. The repository control-plane files are the persistent shared memory for those agents.

Start here:

1. `docs/AI_AGENT_START_HERE.md`
2. `AI_AGENT_HANDOFF.md`
3. `PROJECT_STATE.md`
4. `TASK_QUEUE.md`
5. `docs/ARCHITECTURE.md`

## Current Stage

The project is currently establishing its application/tooling foundation. Live trading and regulated features are disabled by design until their prerequisites are independently verified.

## Development

Use the repository's task queue and handoff protocol. Do not commit secrets. Keep paper and live execution paths isolated. Every completed task requires verification evidence.
